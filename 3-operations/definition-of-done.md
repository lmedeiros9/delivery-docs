# Definition of Done

- **Purpose:** A shared checklist for when a piece of work counts as finished.
- **Owner:** Director of Delivery
- **Last reviewed:** YYYY-MM-DD
- **Applies to:** Everyone on the delivery crew

*This is placeholder content for testing the site.*

## Checklist

A piece of work is done when:

1. It meets the agreed requirements.
2. A second person has reviewed it.
3. It has been tested in a sandbox.
4. The documentation is updated.
5. The Client Lead knows it is ready.

> Check with the Client Lead before marking anything done on a client account.
