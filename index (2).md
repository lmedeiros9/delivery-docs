# 3 | Operations

**Project execution and quality assurance.** How the crew delivers, and the quality bar every project meets.

Client Leads own each project: status, priorities, and client communication. This section defines the system they run it in.

## What lives here

- **Delivery standards:** the cadence, release management, and governance practices Client Leads run their projects by.
- **Methodology:** the Delivery Playbook, and how consistently the crew follows it.
- **Quality and sign-offs:** stage-gate reviews before user acceptance testing (UAT), Maker-Checker, and the Definition of Done.

## How it connects

Operations drives the timeline. [5 | Plans]({{ site.baseurl }}/5-plans/) drives the long-range vision.
