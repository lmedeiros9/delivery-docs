# 4 | Logistics

**Tooling, templates, and reusability.** The crew's internal product team.

If you build something twice, it belongs here. Archive the snippets, flow design patterns, and deployment checklists so the crew never builds the same thing again.

## What lives here

- **Reusable assets:** accelerators, standard data models, flow design patterns, and code repositories.
- **Partner ecosystem:** AppExchange partners and other third-party vendors a build depends on.
- **Provisioning:** sandboxes and scratch orgs, ready when the crew needs them.
- **Deployment tooling:** CI/CD pipelines and release tools (for example Copado, Flosum, or GitHub Actions).
